# Segurança

Se encontrares uma vulnerabilidade, **não abras uma issue pública**. Usa o
[reporte privado de vulnerabilidades](https://github.com/tpereira2005/tento/security/advisories/new) do GitHub.

Este repositório nunca deve conter dados reais (CSVs, folhas de cálculo, bases de dados) nem segredos.
Se vires algum, reporta pelo mesmo canal.
